# AI-DLC v1 Simulator

An interactive, gamified training simulator for AWS AI-DLC (AI-Driven Development Life Cycle) v1, built for software engineers, product owners and project managers.

Players pick a role and follow one change to an illustrative identity risk product through all 11 stages of AI-DLC v1. At each stage they see what the AI reads, what it does, what people decide, what gets written into the project, and who approves. Points and badges reward good habits, such as reviewing what the AI wrote before approving it.

## Learning Lab

`learning-lab/index.html` is a second, self-guided version: the AI-DLC v1 Learning Lab. It teaches the framework step by step in a full-screen workspace with a lesson guide, a file explorer and code editor, an AI assistant chat with a small team, and a working preview of the mock product before and after the change. It saves progress in the browser. Some of the AI's drafts contain planted mistakes to catch before approving, teammates sometimes disagree, and the lab ends with a month of made-up production results that follow from the learner's decisions.

## Running it

Each one is a single self-contained HTML file. Open `index.html` (the simulator) or `learning-lab/index.html` (the Learning Lab) in a browser, or serve them with GitHub Pages.

## Notes

- The scenario, people, times and figures are illustrative and made up for training.
- Folder and file names are simplified versions of the real AI-DLC v1 layout.
- Based on [awslabs/aidlc-workflows](https://github.com/awslabs/aidlc-workflows).
