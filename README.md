# AI-DLC v1 Learning Lab

A self-guided, interactive training lab for AWS AI-DLC (AI-Driven Development Life Cycle) v1, built for software engineers, product owners and project managers.

The Learning Lab teaches the framework step by step in a full-screen workspace with a lesson guide, a file explorer and code editor, an AI assistant chat with a small team, and a working preview of an illustrative identity risk product before and after the change. Progress is saved in the browser. Some of the AI's drafts contain planted mistakes to catch before approving, teammates sometimes disagree, and the lab ends with a month of made-up production results that follow from the learner's decisions.

To run it in a live training call, see the [facilitation guide](learning-lab/FACILITATION-GUIDE.md).

## Running it

The lab is a single self-contained HTML file. Open `learning-lab/index.html` in a browser, or serve it with GitHub Pages.

## Notes

- The scenario, people, times and figures are illustrative and made up for training.
- Folder and file names are simplified versions of the real AI-DLC v1 layout.
- Based on [awslabs/aidlc-workflows](https://github.com/awslabs/aidlc-workflows).
